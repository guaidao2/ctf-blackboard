# CTF Blackboard 1.0.0

第一个正式版本：一块给 CTF 队伍用的实时协同黑板。

## 亮点

- **战果墙**：记录最终是谁交了哪道题的 flag，附 writeup，一键导出 Markdown。
- **容器位**：记录谁占了哪道题的实例、地址和备注；有硬上限，满了拒绝新开，避免把别人顶掉。
- **团队频道**：全队聊天、系统播报、未读数和后台提示音。
- **动态设置**：题目总数、容器位上限、公告随时可改。
- **安全连接**：TLS 1.3 + 首次信任指纹（known_hosts）+ 每会话 AES-256-GCM；密码不传输。
- **单文件分发**：服务端和客户端各一个二进制，前端已内嵌，不需要数据库或运行时。

## 快速开始

```bash
export CTFBB_PASSWORD='换成一串至少 12 位的共享密码'
./ctfbb-server --listen 0.0.0.0:8443 --data ./data --slots 5 --total 20
./ctfbb-client --nick alice
```

首次连接会像 SSH 一样显示服务器指纹，确认后记住；下次自动校验。服务端生成的 `server-info.txt` 是可选的免提示快捷方式。

## 校验

```bash
sha256sum -c --ignore-missing checksums.txt
```

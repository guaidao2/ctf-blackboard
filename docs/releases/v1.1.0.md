# CTF Blackboard 1.1.0

稳定性版本：大黑板不再受单帧大小限制，登录限速也不再被并发绕过。

## 亮点

- **超大快照分片传输**：快照、`state.get` 响应和广播超过 1 MiB 时自动拆成多个加密帧，客户端重组。  
  不删除战果，不裁剪释放历史，不设置状态条数上限。
- **单帧仍为 1 MiB**：没有为了大快照放宽加密帧边界。分片只是把逻辑消息拆开。
- **登录限速修复**：尝试在 PBKDF2/HMAC 之前预占并发名额；失败预算 8 次/5 分钟与并发上限 32 分开。  
  同一出口 IP 的队员可以同时登录，错误口令仍然受限。
- **协议升级到 v2**：客户端和服务端必须一起升级；旧 v1.0.0 客户端会收到明确的协议版本不匹配，而不是静默断线。
- **传输保护**：服务端接收客户端消息上限 4 MiB，客户端接收服务端消息上限 64 MiB；超限会收到 `server.error` 事件，不是静默断开。
- **分片防护**：乱序、混入其它消息、30 秒无后续分片会断开；重组缓冲用后立即释放。

## 升级说明

这是协议 v2 版本：

- **服务端和客户端必须同时升级**。
- v1.0.0 客户端连接 v1.1.0 服务端会收到协议版本不匹配。
- 数据目录、`state.json`、known_hosts 不需要迁移。
